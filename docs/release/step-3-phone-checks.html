Step 3 of the release notes (docs/release/README.md). These are the checks that only a real phone can answer. Each check says what to do and what you should see. Write what you really saw in the box on the right, and tick one of the three small boxes.

Item 12: the two questions

If you forget your master password, the app lets you choose a new one with your PIN (or your fingerprint, when there is no PIN). The new one starts working only after 24 hours, counted while the phone is switched on. The wait protects you: if someone saw your PIN and chose a new master password, the app shows a warning with Cancel it, and you have those hours to see it. During the wait no backup can be made.

Question 1. Is 24 hours with the phone switched on the right wait?

The hours count only while the phone is on. If you switch the phone off every night, the wait takes longer:

  • about a day and a half, if you open the app in the morning and in the evening;
  • about 3 days, if you open it once a day, in the evening;
  • about 3 weeks, if you open it only once, soon after switching the phone on.
Keep 24 hours.
Count fewer hours, for example 12.
Let the app look at the clock by itself while it waits: a silent alarm every hour or two. It needs no permission, but the app would then wake up in the background now and then, which it never does today, and after the phone restarts it would only start again once you open the app.

Question 2. Should the app show a notification during that wait?

Today the warning is a banner inside the app. If you do not open the app during the wait, you do not see it. An Android notification would reach you even then. It needs no internet. On Android 13 and newer the phone asks you once whether the app may show notifications. Its words would give nothing away to someone who looks at your phone.

Box A: the limiter's state, and a limit just above what the app needs

{
ADB=/home/asus/Android/Sdk/platform-tools/adb
PHONE=$($ADB devices -l | awk '/ usb:/ && $2 == "device" {print $1; exit}')
if [ -z "$PHONE" ]; then echo "STOP: no phone found. Do step 2, part 2.8 again."; else
  STATE=$($ADB -s "$PHONE" shell am memory-limiter status | tr -d '\r'); echo "$STATE"
  PID=$($ADB -s "$PHONE" shell pidof io.github.dilshodbekmx.passwordvault | tr -d '\r')
  KB=$($ADB -s "$PHONE" shell cat /proc/meminfo | awk '/^MemTotal/ {print $2}')
  ABOVE=$(( (225280 * 100 + KB - 1) / KB ))
  if printf '%s' "$STATE" | grep -q disabled; then echo "This phone's limiter is disabled: write \"disabled\" for check 13. Nothing was set."
  elif [ -z "$PID" ]; then echo "STOP: PasswordVault is not running. Open it (point 1), then paste this box again."
  else $ADB -s "$PHONE" shell am memory-limiter manual "$PID" "$ABOVE" && echo "DONE: limit $ABOVE % of the phone's memory set for PasswordVault."; fi
fi
}

Box B: a limit just below what the app needs

{
ADB=/home/asus/Android/Sdk/platform-tools/adb
PHONE=$($ADB devices -l | awk '/ usb:/ && $2 == "device" {print $1; exit}')
if [ -z "$PHONE" ]; then echo "STOP: no phone found. Do step 2, part 2.8 again."; else
  PID=$($ADB -s "$PHONE" shell pidof io.github.dilshodbekmx.passwordvault | tr -d '\r')
  KB=$($ADB -s "$PHONE" shell cat /proc/meminfo | awk '/^MemTotal/ {print $2}')
  BELOW=$(( (225280 * 100 + KB - 1) / KB - 1 ))
  if [ -z "$PID" ]; then echo "STOP: PasswordVault is not running. Open it, then paste this box again."
  elif [ "$BELOW" -lt 1 ]; then echo "This phone has so much memory that no lower limit exists: write \"too much memory\" for check 13."
  else $ADB -s "$PHONE" shell am memory-limiter manual "$PID" "$BELOW" && echo "DONE: limit $BELOW % of the phone's memory set for PasswordVault."; fi
fi
}

Box C: remove the limit, and show how the app ended

{
ADB=/home/asus/Android/Sdk/platform-tools/adb
PHONE=$($ADB devices -l | awk '/ usb:/ && $2 == "device" {print $1; exit}')
if [ -z "$PHONE" ]; then echo "STOP: no phone found. Do step 2, part 2.8 again."; else
  PID=$($ADB -s "$PHONE" shell pidof io.github.dilshodbekmx.passwordvault | tr -d '\r')
  if [ -n "$PID" ]; then $ADB -s "$PHONE" shell am memory-limiter manual "$PID" none && echo "DONE: the limit is removed."; else echo "PasswordVault is not running: it has no limit any more."; fi
  echo "How PasswordVault ended last time:"
  $ADB -s "$PHONE" shell dumpsys activity exit-info io.github.dilshodbekmx.passwordvault | tr -d '\r' | grep -m1 -A5 'ApplicationExitInfo #0'
fi
